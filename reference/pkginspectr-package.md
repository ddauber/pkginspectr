# pkginspectr: Tidy Tools for Inspecting and Comparing R Package Structure

Inspect the structure and source code of R packages from local folders,
'GitHub' repositories or 'CRAN'. Summarise file counts, folder structure
and lines of code (blank, comment, 'roxygen', function and test lines)
as tidy tibbles. Lines are classified with R's own parser, and files
excluded by '.Rbuildignore' are skipped, so local folders and released
packages can be compared on equal terms. Compare several packages side
by side and visualise the results as Unicode bar charts in the console.
